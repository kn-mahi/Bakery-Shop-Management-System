# Bakery Shop Management System
An academic desktop application developed using **C# Windows Forms** and **SQL Server** to manage bakery shop operations.

## Features
- Login & Registration
- Employee Management
- Product & Category Management
- Inventory & Stock Control
- Sales Report
- Shopping Cart & Order Processing
- Automatic Bill Calculation
- CRUD Operations
